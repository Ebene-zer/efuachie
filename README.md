# Ebenezer Fuachie – Portfolio Website

Personal portfolio website showcasing projects, skills, and my overall software engineering journey.

---

##  Tech Stack
- **Next.js**
- **Tailwind CSS**  
- **Framer Motion** 
- **Vercel** 
---


##  Project Structure
```
public/ #assets
src/
├─ components/ # Reusable UI components (Navbar, Footer, etc.)
├─ layouts/ # Common page layouts
├─ pages/ # Website pages (Home, About, Projects, Skills, Contact)
├─ styles/ # Global styles and Tailwind setup
├─ data/ # Project and content data
└─ utils/ # Constants and helper functions

```
